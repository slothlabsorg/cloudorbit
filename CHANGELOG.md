## [0.1.0] — 2026-03-xx

### Added
- AWS SSO login with device authorization flow
- Multi-account session management with expiry tracking
- EKS cluster discovery and `~/.kube/config` update
- EC2 instance listing with SSM browser session support
- Federated AWS Web Console login
- Auto-updater with changelog popup (Tauri updater plugin)
- macOS, Windows, and Linux native builds
- Homebrew Cask and WinGet distribution
- Orbit Overview with stat cards and real-time session status
- Activity log with filterable event history
- Docs screen with in-app getting-started guide
- Support screen linking to Ko-fi and GitHub Sponsors
